# Experimental bare-metal stubs (quarantined)

These files were previously scattered at the repository root next to an incomplete
`Cargo.toml` (`rust-os`) that expected `src/main.rs`. They are **not** part of the
primary IntentKernel Rust prototype (`rust/`).

The intentional ISO/bare-metal path is [`iso-build/`](../../iso-build/), especially
`iso-build/rust-os/`.

Do not treat this directory as a supported build target.
