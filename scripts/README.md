# Host helper scripts

Optional Windows/PowerShell and PQC build helpers.
They are **not** part of the primary IntentKernel verification path.

Use:

```bash
cd rust
cargo test --workspace
cargo run -p intentos -- -c status
```

See root [`BUILD.md`](../BUILD.md) and [`docs/REPO_LAYOUT.md`](../docs/REPO_LAYOUT.md).
